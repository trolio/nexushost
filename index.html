🔗 Node Agent Installation

Run this PowerShell command on each Windows machine you want to add as a node

irm https://nexushost.local/agent/install.ps1 | iex -Token YOUR_PANEL_TOKEN

The agent runs as a Windows Service on port 8080 and communicates back to this panel over websocket.
